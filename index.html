One-time setup (about 5 minutes)
  1. Sign in at github.com (or create a free account).
  2. Tap New repository. Name it baraka-backups, choose Private, tick Add a README, then create it.
  3. Profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Name it "Baraka", expiry 1 year, Only select repositories → baraka-backups. Under Repository permissions set Contents to Read and write. Generate it and copy the token.
  4. Come back here, type yourname/baraka-backups, paste the token and tap Connect GitHub.

Saves one file per day in a "backups" folder, updated in place, so there are no duplicates. It refuses to upload if the repository is public. The token stays on this phone and only works for that one repository.

One-time setup (about 10 minutes)
  1. Open console.cloud.google.com and create a project, for example "Baraka".
  2. APIs & Services → Library: search for "Google Drive API" and press Enable.
  3. OAuth consent screen: choose External, name it "Baraka Receipt", add your Gmail as a Test user, then press Publish app so sign-in does not expire after a week.
  4. Credentials → Create credentials → OAuth client ID → Web application. Under Authorized JavaScript origins add the address shown below. Create it, copy the Client ID and paste it above.
  5. Tap Connect Google Drive and allow access. Done.
